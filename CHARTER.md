# Package charter

Portal Contract owns immutable portal declarations, explicit owner/capability admission and bounded presentation
contracts. Core retains authority, transactions, persistence, active contribution registries, trust, HTTP, rendering,
delivery, deployment and recovery. SDK retains executable delivery interfaces.

The package has no SDK dependency, alternate application host or copied lower-level semantic implementation.
Public types enforce only their documented portable invariants. Contribution and Access Control retain canonical
ownership of their identity/policy and capability contracts. No aliases or dual production owners are supported.
Package publication, independent artifact verification and Core acceptance require distinct evidence.
